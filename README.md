## Online Food Ordering System Website

This project is a web-based Online Food Ordering System developed using PHP, HTML, CSS, JavaScript, and MySQL. It allows users to browse food items, add them to a cart, and place orders online. The project demonstrates full-stack web development with both frontend and backend functionality.

**Features**:

1. User registration and login
2. Browse food menu by category
3. Add and remove items from cart
4. Place food orders
5. View order summary
6. Admin panel to manage food items and orders

**Technologies Used**:

- PHP
- MySQL
- HTML
- CSS
- JavaScript

**How to Run the Project**:

1. Install XAMPP or WAMP on your system
2. Copy the project folder into the htdocs folder (for XAMPP)
3. Start Apache and MySQL from XAMPP control panel
4. Import the database file (.sql) into phpMyAdmin
5. Open a browser and run the application using: http://localhost/OnlineFoodOrderingSystem/
